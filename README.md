# YSL, YccShardLauncher

A modlauncher for StoneShard-YCC built in Rust.
> It uses the nightly channel
> It does not rely on YYToolkit

## For users

- Download the [last release](https://github.com/ModShardTeam/YccShardLauncher/releases)
- unzip the folder
- run `injector.exe`

```shell
injector.exe PATH/TO/STONESHARD.exe
```

## For devs

- Clone it
- Run it:

```shell
cargo run -- PATH/TO/STONESHARD.exe
```
